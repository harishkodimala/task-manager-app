# Task Manager App

A modern and responsive Task Manager application built to help users organize, manage, and track their daily tasks efficiently. This project focuses on clean UI design, CRUD operations, and responsive user experience using modern web development technologies.

---

## 🚀 Features

* ✅ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* 📌 Mark tasks as completed
* 📋 Task organization
* 🔍 Filter and manage tasks
* 📱 Fully responsive design
* ⚡ Fast and interactive UI
* 🎨 Clean and modern interface

## 💻 Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/harishkodimala/task-manager-app.git
```

### Navigate to Project Folder

```bash
cd task-manager-app
```

---

## ▶️ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

## ▶️ Backend Setup

```bash
cd backend
npm install
npm start
```

Backend runs on:

```bash
http://localhost:5000
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
